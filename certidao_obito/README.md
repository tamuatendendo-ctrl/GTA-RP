# Certidão de Óbito — Carapicuíba RP

Preenchimento de certidão de óbito para o servidor Carapicuíba RP.

## Publicação no Streamlit Community Cloud

1. Envie os arquivos desta pasta para a raiz de um repositório GitHub.
2. No Streamlit Community Cloud, selecione **Create app**.
3. Escolha o repositório, a branch e o arquivo principal `app.py`.
4. Clique em **Deploy**.

O HTML foi mantido como interface incorporada. Os botões de exportação dependem do carregamento das bibliotecas JavaScript externas incluídas no HTML.
